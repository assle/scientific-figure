OpenCode 使用速查

路径、启动命令、工作流和故障定位集中在一页。

固定路径

PACKAGE=/path/to/scientific-figure/scientific-figure-builder
CONFIG=$HOME/.config/opencode/opencode.json

首次安装

cd "$PACKAGE"
uv sync --extra ark

mkdir -p "$HOME/.config/opencode/skills" "$HOME/.config/opencode/commands"
ln -sfn "$PACKAGE" \
  "$HOME/.config/opencode/skills/scientific-figure-builder"
ln -sfn "$PACKAGE/commands/scientific-figure.md" \
  "$HOME/.config/opencode/commands/scientific-figure.md"

uv run python install/configure_opencode.py \
  "$CONFIG" "$PACKAGE"

每次启动

set -a
. "$PACKAGE/.ark.env"
set +a
cd /path/to/your-paper-project
opencode

标准顺序

命令作用是否可能付费
/scientific-figure init创建项目配置否
/scientific-figure plan …生成计划和线框图参考图分析可能调用视觉模型
/scientific-figure run执行已批准计划是
/scientific-figure resume从中断处继续仅未完成步骤
/scientific-figure validate检查资产和整图语义检查可能付费
/scientific-figure export导出 PNG/SVG/PDF/PPTX通常否

快速检查

opencode mcp list
test -f .scientific-figure/project.yaml
test -d runs
