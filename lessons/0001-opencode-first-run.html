第一次在 OpenCode 使用 Scientific Figure Builder

目标：正确接入三个部件，并完成一次“计划 → 审批 → 执行 → 导出”。

当前状态：代码和 Ark 配置已存在；OpenCode 中的 Skill、命令和 MCP 尚未安装。

先理解三个部件

  • Skill：告诉 OpenCode 如何拆分和编排科研图。
  • Command：提供 /scientific-figure 入口。
  • MCP：真正执行 Python、SVG 和火山方舟调用。

只复制 Skill 不够；缺少 MCP 时，OpenCode 知道流程却没有执行工具。

第一步：一次性安装

PACKAGE=/path/to/scientific-figure/scientific-figure-builder
CONFIG="$HOME/.config/opencode/opencode.json"

cd "$PACKAGE"
uv sync --extra ark

mkdir -p "$HOME/.config/opencode/skills" "$HOME/.config/opencode/commands"
ln -sfn "$PACKAGE" \
  "$HOME/.config/opencode/skills/scientific-figure-builder"
ln -sfn "$PACKAGE/commands/scientific-figure.md" \
  "$HOME/.config/opencode/commands/scientific-figure.md"

uv run python install/configure_opencode.py \
  "$CONFIG" "$PACKAGE"

最后一条命令会展示配置差异并询问是否应用。确认后，它会备份原配置，只增加 scientific-figure MCP。

第二步：带 Ark 环境启动 OpenCode

set -a
. "$PACKAGE/.ark.env"
set +a

cd /path/to/your-paper-project
opencode

.ark.env 不会被 OpenCode 自动读取。必须先加载环境变量，再从同一终端启动 OpenCode。修改模型 ID 或 Key 后也要重启。

第三步：确认接入成功

opencode mcp list

应看到 scientific-figure 已连接。在 OpenCode 输入 /scientific-figure 时，也应出现自定义命令。

第四步：初始化论文项目

在论文项目目录启动 OpenCode，然后输入：

/scientific-figure init

成功后应生成：

.scientific-figure/
├── project.yaml
├── style_bible.json
└── .gitignore

第五步：先做一个低风险数据图

/scientific-figure plan 使用 @data/coupling.csv 绘制耦合效率折线图。
横轴为 wavelength_nm，纵轴为 efficiency。
先生成计划和线框图，不执行付费图片生成。

检查数据列、单位、画布和输出格式。确认无误后回复：

我批准这个计划，请执行 run。

第六步：运行混合科研图

/scientific-figure plan 制作双面板论文图：
(a) 根据 @references/setup.png 重绘实验装置；
(b) 使用 @data/coupling.csv 绘制耦合效率曲线。
文字和箭头用 SVG，数据图用 Python，AI 只生成独立器件素材。

运行前必须检查四件事：

  • 将上传哪些参考图
  • 预计调用哪些模型以及次数
  • 线框布局是否正确
  • 是否存在科学结构或单位不确定项

批准计划后执行。若 AI 素材达到三个，流程会先给出风格锚点，需再次确认。

第七步：查看结果

结果位于项目的版本化 runs/ 目录。正式输出通常包括：

exports/figure.png
exports/figure.svg
exports/figure.pdf
asset_manifest.json
validation_report.json
generation_report.md

最常见的三个问题

命令不存在：检查全局 command 软链，然后重启 OpenCode。

MCP disconnected：运行 opencode mcp list；确认 uv 可执行且配置中的 package 路径存在。

意外使用 mock：六个 Ark 环境变量必须在启动 OpenCode 前全部加载。

一次小测

如果你只是要根据 CSV 画折线图，应该让 Ark 生图模型生成曲线吗？

  1. 应该，因为图片模型更快
  2. 不应该，应由 Python 按数据精确绘制
  3. 都可以，只要最后看起来相似
查看答案

答案是 2。数据、坐标轴、数值和误差棒必须走 Python。
