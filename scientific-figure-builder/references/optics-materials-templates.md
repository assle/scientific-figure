# Optics-materials domain templates

Domain-specific templates for optics and materials figures.

> Status: **seeded in Phase 1; expanded as domain recipes are added.**

Reserved categories (plan section 2 examples):

- Optical-fiber bodies and cross-sections.
- Periodic gratings and arrays (Python/SVG only).
- Beams, rays, and coupling-efficiency curves.
- Labels, angles, and equations (SVG/PPTX).

Each domain template will reference a `style_bible.json` and a set of plot
recipes from `templates/plot-recipes/`. No complex photorealistic equipment is
produced via SVG; such assets route to the Ark image model as isolated objects.
