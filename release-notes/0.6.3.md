# Scientific Figure Builder 0.6.3

Scientific Figure Builder 0.6.3 re-checks a data plot against its source data on
every execution pass instead of trusting the render that produced it.

## Execution

- Validates each data plot against its source data on every pass, including a
  plot reused from an earlier pass, because the Plot spec or its source data may
  have changed after the render.
- Reports a skipped plot-data check when a rendered plot has no `data_used.csv`
  next to it, instead of comparing the source data against itself and passing.
- Moves plot-data validation out of the renderer: `render_plot` now returns only
  the rendered file paths, and the caller owns the validation report.
