# Scientific Figure Builder 0.6.1

Scientific Figure Builder 0.6.1 fixes two defects that interrupted figure
workflows after 0.6.0.

## Equation preview

- Normalizes matplotlib SVG root `width` and `height` from `pt` to `px` while
  keeping the `viewBox`, so equation preview no longer fails with
  `ValueError: SVG has an invalid size`.

## Planning contract

- Constrains the nested `style_bible` field in `planning-advice.schema.json` to
  the Style Bible contract instead of accepting any object.
- Sends the planning schema with the phase request so an invalid Style Bible
  fails at the schema boundary instead of exhausting the per-run reasoning
  budget.

## Verification

The tag Release workflow runs the complete automated test suite, Pyright, Core
wheel build, Product-bundle build, manifest verification, and checksum
generation before creating the GitHub Release.
