# Scientific Figure Builder 0.6.4

Scientific Figure Builder 0.6.4 fixes transient Windows file-access failures in
workflow state persistence and explains the Configuration app options in both
READMEs.

## Reliability

- Retry short-lived permission errors when replacing Run Store JSON/text
  artifacts and when reading JSON artifacts and their references. This prevents
  concurrent state polling and persistence from unnecessarily pausing a workflow
  or reporting its state file as corrupt on Windows.
- Share bounded file-access retry behavior with Cache replacement. Persistent
  errors still propagate; failed commits preserve the previous artifact and
  remove temporary files.

## Documentation

- Explain model roles, Provider protocols and image capabilities, waiting and
  retry controls, phase output allowances, credentials, connection testing, and
  global versus project configuration in the English and Chinese READMEs.
