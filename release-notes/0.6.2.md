# Scientific Figure Builder 0.6.2

Scientific Figure Builder 0.6.2 refreshes the configuration app and the project
presentation, and stops publishing repository-private documentation.

## Configuration app

- Redraws the navigation sidebar, cards, inputs, and buttons with the refreshed
  palette, radii, and spacing, without changing any configuration behavior.
- Places the request-policy and output-token editors of a Model route side by side
  so a phase role is edited in one row.

## Repository

- Removes maintainer and agent-facing documentation from the published tree and
  keeps it local through `.gitignore`; the README is the published documentation
  entry point and the user guide remains available.
- Regenerates the banner, workflow diagram, and demonstration figures used by the
  README, and updates the user guide with command-context guidance.

## Verification

The tag Release workflow runs the complete automated test suite, Pyright, Core
wheel build, Product-bundle build, manifest verification, and checksum generation
before creating the GitHub Release.
