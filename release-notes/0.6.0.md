# Scientific Figure Builder 0.6.0

Scientific Figure Builder 0.6.0 separates publishing, Local activation, and
host reload while replacing the previous manual multi-command update process.

## Release and activation

- Adds a resumable maintainer Release Pipeline with an immutable-tag guard and
  an optional Local activation composition.
- Publishes a complete Product bundle, Core wheel, Release manifest, and
  detached SHA-256 checksums from the tag workflow.
- Adds verified online Release resolution and offline Product-bundle activation.
- Makes complete Codex activation available through the Release-aware root
  installer while retaining an explicit Core-only compatibility path.

## Local status and cleanup

- Adds `scientific-figure status` with JSON, verbose, and explicit remote modes.
- Adds `scientific-figure update` with exact Release, latest Release, and local
  bundle inputs.
- Reports converged, update-available, restart-required, inconsistent, and
  broken local states with stable exit codes.
- Preserves Provider configuration, Model routes, credential references,
  project data, and run artifacts while replacing product-owned files.
- Protects Runtime directories used by live MCP or GUI processes, then removes
  superseded Runtime and Plugin cache versions after convergence.
- Retains only the ten most recent redacted installation transaction logs.

## Compatibility

- Product version `0.6.0` changes the root `--codex` path to mean complete,
  Release-aware Codex activation. Use `--runtime-only` for Core-only delivery.
- MCP and the Configuration app remain on-demand; installation reports when a
  Codex or OpenCode reload is required and does not terminate active work.

## Verification

The tag Release workflow runs the complete automated test suite, Pyright, Core
wheel build, Product-bundle build, manifest verification, and checksum
generation before creating the GitHub Release. Paid Provider calls and real
PowerPoint GUI acceptance remain explicitly separate.
