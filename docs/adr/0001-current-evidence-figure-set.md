# Use a five-figure main-text package for the current trapezoid-only manuscript

The current manuscript will use one graphical abstract, five main-text figures, and one supplementary interaction atlas. This package is limited to completed trapezoidal-grating evidence and is organized around the claim that interpretable parameter-space mapping improves finite-budget search reliability; unfinished numerical validation, \(H_z\) boundary scans, tolerance studies, and parallelogram comparisons do not reserve figure numbers.

## Figure responsibilities

1. **Physical model** — trapezoidal geometry, four design parameters, material regions, excitation, periodic boundaries, and target transmitted order.
2. **Global efficiency landscape** — polarization-specific efficiency distributions, marginal parameter responses, high-efficiency occurrence rates, influence rankings, and candidate high-efficiency intervals.
3. **Core interaction evidence** — period–height efficiency maps, rankings of all six parameter-pair interaction scores, and selected fill-factor interaction maps.
4. **\(E_z\) basin-refinement case** — four one-dimensional scans, the period–height map, and the sidewall-angle–fill-factor boundary map.
5. **Search-reliability evidence** — best-so-far trajectories, best-of-run outcomes, and threshold-qualified candidate yields for broad and focused searches under equal budgets.

Supplementary Fig. S1 will contain the complete pairwise mean-efficiency atlas for both polarizations.

## Considered options

A separate efficiency-distribution figure was rejected because its evidence fits naturally within the global-landscape figure. Twelve pairwise maps were rejected for the main text because they obscure the dominant period–height interaction. Splitting the \(E_z\) scans across two main figures was rejected because it would overemphasize a polarization-specific case. Planned but unfinished studies were excluded because the figure numbering should represent current evidence rather than anticipated results.

## Consequences

The graphical abstract alone carries the end-to-end workflow, while Fig. 1 remains a physical-model definition. Fig. 4 must be described as an \(E_z\)-specific case rather than cross-polarization validation. Candidate-level yields in Fig. 5 remain descriptive because evaluations within each optimizer run are dependent.
